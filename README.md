# 뉴스 검색 웹앱

키워드와 날짜 범위로 Google News RSS를 검색하고, 기사 링크와 자동 분류 태그를 보여주는 간단한 Flask 웹앱입니다.

## 실행

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
py app.py
```

브라우저에서 `http://127.0.0.1:5000`을 여세요. 검색 결과는 인터넷 연결이 필요합니다.

## 모바일 및 다른 기기에서 접속하기 (Render 배포)

휴대폰에서도 접속하려면 앱을 인터넷에 공개된 서버에 배포해야 합니다. 이 프로젝트에는 Render용 설정 파일(`render.yaml`)이 포함되어 있습니다.

1. 프로젝트 파일을 본인의 GitHub 저장소에 올립니다. GitHub에 저장소가 없다면 새 저장소를 만든 뒤, 이 폴더를 업로드하세요.
2. Render 계정에 로그인하고 **New + → Blueprint**를 선택한 다음, 방금 올린 GitHub 저장소를 연결합니다.
3. Render가 `render.yaml`을 읽어 웹 서비스를 만들면 배포가 시작됩니다. 빌드와 배포가 끝나면 대시보드에서 `https://...onrender.com` 주소를 확인하세요.
4. 그 HTTPS 주소를 휴대폰이나 다른 기기에서 열면 됩니다. 검색할 때는 해당 기기도 인터넷에 연결되어 있어야 합니다.

코드 변경을 GitHub에 올리면 연결된 Render 서비스가 다시 배포됩니다. 공개 주소는 누구나 열 수 있으므로 내부 전용으로 써야 할 검색 자료는 입력하지 마세요. 호스팅 서비스의 요금과 휴면 정책은 계정 및 시점에 따라 달라질 수 있으니 배포 전에 Render 대시보드에서 확인하세요.

## 참고

- 결과 개수는 10~30개로 설정할 수 있습니다.
- 날짜 범위로 RSS 검색을 요청한 뒤, 게시일을 다시 확인해 기간 밖 기사를 제외합니다.
- 링크는 Google News RSS가 제공하는 기사 링크이며 언론사 페이지로 연결됩니다.
- 사업 분류와 분야 태그는 `app.py`의 키워드 규칙을 기준으로 자동 지정됩니다. 필요에 따라 규칙을 추가할 수 있습니다.
